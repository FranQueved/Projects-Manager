🚀 CÓMO COMENZAR

OPCIÓN 1: Rápida (2 minutos)
────────────────────────────

Terminal 1:
$ cd backend
$ pip install -r requirements.txt
$ python -m uvicorn app.main:app --reload

Terminal 2:
$ cd frontend
$ npm install
$ npm start

Accede a: http://localhost:3000

Lee SETUP.md y sigue los pasos paso a paso.
